# SystemFix Security

Сканер уязвимостей Windows: ищет типовые слабые места конфигурации и умеет их исправлять. Чистый PowerShell 5.1 (встроен в Windows), без сторонних пакетов и без доступа в интернет.

## Запуск

| Что | Как |
| --- | --- |
| Только скан (ничего не меняет) | `powershell -ExecutionPolicy Bypass -File .\app\Scan-Fix.ps1` |
| Скан + исправления с подтверждением | запуск `app\Launch-Fix.cmd` (сам запросит права администратора) |
| Сохранить HTML-отчёт | `.\app\Scan-Fix.ps1 -ReportPath .\report.html` |

## Что проверяется

1. Защитник Windows — защита в реальном времени и свежесть сигнатур.
2. Брандмауэр — включены ли все профили (Домен/Частный/Публичный).
3. SMBv1 — уязвимость EternalBlue (MS17-010).
4. UAC — не отключён ли контроль учётных записей.
5. RDP — включён ли удалённый рабочий стол без сетевой аутентификации (NLA).
6. NTLM — не разрешены ли устаревшие LM/NTLMv1.
7. TLS 1.0/1.1 — не включены ли на уровне SCHANNEL.
8. Парольная политика — минимальная длина пароля.
9. Гостевая учётная запись — не включена ли.
10. Автозапуск со сменных носителей.
11. Secure Boot — включён ли (только проверка, включается в UEFI/BIOS).
12. Центр обновления Windows — как давно ставились обновления.
13. Общие папки — нет ли доступа Everyone (Full).

## Безопасность

- По умолчанию скрипт **только читает** состояние системы и печатает отчёт.
- Каждое исправление выполняется **только после вашего `y`** и требует прав администратора.
- Исправления меняют только перечисленные выше настройки (реестр, службы, компоненты) и не удаляют файлы.
- После исправлений SMBv1, UAC и TLS потребуется **перезагрузка**.
- Перед массовыми изменениями на рабочей машине рекомендуется создать точку восстановления системы.

## Ограничения

Это проверка конфигурации, а не антивирус и не сканер эксплойтов: он не ищет вредоносные файлы и не анализирует сетевой трафик. Полный аудит требует инструментов вроде Microsoft Defender Vulnerability Management.
